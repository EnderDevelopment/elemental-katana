# Elemental Katana

Elemental Katana is a Minecraft plugin that adds various types of katanas to the game, including elemental katanas like Shadow, Fire, Water, Cloud, Earth, and Wind. Each katana has unique properties and abilities, enhancing the gameplay experience.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Use the command `/givekatana <type>` to give yourself a katana. Replace `<type>` with one of the following: iron, diamond, shadow, fire, water, cloud, earth, wind.
2. Example: `/givekatana shadow` will give you a Shadow Katana.
